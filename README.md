# mc-map-atelier

**Maps, atelier-made.**

> Map atelier for Minecraft - place structures and export to schematic or WorldEdit.

## Features

- 2D top-down Minecraft map
- Place schematics, drag to move
- Export to .schem or //paste commands

## Hand-crafted TS

\\\	s
export function toSchematic(objects: MapObject[]) {
  const header = "// Generated by mc-map-atelier\n";
  return header + objects.map(o => 'minecraft:stone ' + o.x + ' ' + o.y + ' ' + o.z).join('\n');
}
